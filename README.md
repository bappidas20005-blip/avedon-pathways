# Avedon Pathways

Yes. I would not make this as a normal “company profile” website. Since Avedon Education has multiple education brands, the better approach is to build it as a parent education ecosystem website where someone can immediately understand:

Avedon Education → its brands → who each brand is for → courses → results → centres → admissions

From what I found, the ecosystem already spans school education, competitive exams, APSC/UPSC, NEET/JEE and technology/EdTech. Scordemy itself positions around regional-language education and covers exams such as APSC, UPSC, SSC, Banking, TET, JEE and NEET.

26. Important: Don't duplicate Scordemy's existing website

This is very important for your project.

Scordemy already has its own platform with courses, enrollment, app access, categories, etc.

So the Avedon website should be the parent corporate/ecosystem layer.

Think:

                 AVEDON.IN

                     │

          ┌──────────┼──────────┐

          │          │          │

      EXSchool    Scordemy    Avedon AI

                     │

              ┌──────┴──────┐

             APSC          UPSC

              │             │

          Scordemy IAS / Competition Care

The user discovers the brand through Avedon, then goes into the relevant brand's own platform.

27. Design direction I'd recommend

Don't make it look like a traditional coaching institute website.

Style

Modern Indian EdTech + Corporate

Think:

 Large typography

 White / off-white background

 One strong Avedon brand colour

 Huge student/faculty photography

 Smooth animations

 Rounded cards

 Subtle gradients

 Lots of whitespace

 Editorial-style sections

 Interactive statistics

Avoid:

❌ Too many red/blue boxes
❌ 20 banners on homepage
❌ Excessive text
❌ Cheap-looking stock images
❌ Every course dumped on homepage
❌ Too many popups

29. And technically, I would build it as a CMS

Since this company has multiple brands + branches + courses + faculty + results + events, don't hardcode everything.

Your admin should be able to manage:

Brands

 ├── EXSchool

 ├── Scordemy

 ├── Scordemy IAS

 ├── Medical/JEE

 └── Avedon AI

Programs

Faculty

Results

Testimonials

Centres

Events

News

Gallery

Job openings

Leads

FAQs

That way the client can add:

“New Guwahati centre”

or

“New UPSC batch”

without asking you to change React code every time.

My strongest recommendation: position the website as “Avedon Education — the parent ecosystem”, rather than another coaching website. The existing Scordemy ecosystem already demonstrates that the individual brands need their own course/enrollment experiences; Avedon should give the visitor the big picture, credibility, discovery and conversion path.

If you're building this as the actual project, the next step should be to turn this into a complete sitemap + page-by-page UI specification + database/CMS structure, before starting the React/Tailwind development.
